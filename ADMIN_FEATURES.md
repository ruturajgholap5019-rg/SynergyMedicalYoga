# Admin Features

## Available Now

- Protected admin login through normal auth.
- Products list/create/edit/delete.
- Users list/create/edit/delete.
- Orders list/status update/delete.
- Website CMS content list/create/publish/delete.
- Contact enquiry list and status updates.

## Backend Routes Available For Expansion

- `/api/admin/products`
- `/api/admin/users`
- `/api/admin/orders`
- `/api/admin/content`
- `/api/admin/contact-messages`
- `/api/admin/carousels`
- `/api/admin/services`
- `/api/admin/appointments`
- `/api/admin/settings`
